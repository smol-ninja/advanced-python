# Advanced Python

This book has 39 short Python lessons. Each lesson has one code example and three quiz questions.

The reading estimate is two minutes per lesson. Quiz time is not included.
The text uses Simplified Technical English guidance.

## Start the website

```sh
git clone https://github.com/smol-ninja/advanced-python.git
cd advanced-python
python3 serve.py
```

Open [http://localhost:3000](http://localhost:3000).
Press Ctrl+C in the terminal to stop the server.
On macOS, `Start.command` can also start the server.

The website includes its Python browser runtime. No package installation or API key is necessary.
The thread example in Chapter 38 uses Python installed on your computer.

## Study progress

The browser keeps chapter status, quiz answers, bookmarks, and code drafts.
The Study progress page can export and import a backup.
A different browser or port has different storage.
